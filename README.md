# Дмитрий Устинов — робототехника и RoboKit

Статический сайт для GitHub Pages. `index.html` — профиль, проекты, хронология побед по годам, раскрывающийся полный реестр, документы и фотографии; `resume.html` и `hsv.html` сохранены.

## Содержимое

- `docs/robokit-tdp-ru.pdf`, `docs/robokit-tdp-en.pdf` — TDP по 3 страницы. Основной сайт: https://starkit.su/.
- `data/achievements.json` — 104 записи с источниками. 94 относятся к гуманоидным лигам; 10 — к олимпиадам, хакатонам и смежным командам.
- `docs/robokit-achievements.csv` — полный реестр для скачивания.
- `assets/photos/SOURCES.md` — происхождение фотографий и ссылки на Telegram.

Реестр обновлён 14 октября 2026 года: добавлены четыре результата Робофиниста (4 октября) из https://t.me/robofootball/398. Первые места не смешиваются с призовыми; диплом III степени не считается третьим местом. Итоги относятся к изученным источникам, а не к гарантированно полной истории клуба. Победы StarKit не присвоены школьной команде.

## Локальный просмотр

Запустить HTTP-сервер из корня репозитория, например `python3 -m http.server 8765`, и открыть http://localhost:8765/.

Проверка структуры: `python3 scripts/check_site.py`. После изменения данных синхронизируйте JSON, CSV и HTML; проверка сверяет строки и источники. Фотографии выводятся в исходном цвете; оформление страницы остаётся строгим и чёрно-белым.

Хронология оформлена после просмотра https://starkit.su/achievements/. Результаты StarKit МФТИ не добавлены в школьный зачёт RoboKit; ссылка на награды StarKit доступна рядом с итогами по годам.

Расширенная хронология использует чередующиеся карточки и фотографии по образцу раздела наград StarKit, с чёрно-белым оформлением карточек и цветными фотографиями. Снимки 2024 и 2025 годов — соответствующие публикации @robofootball. Раздел выставок содержит подтверждённую демонстрацию на ПМЭФ-2026 и день открытых дверей Физтех-лицея.

`data/award-statistics.json` содержит итоговую статистику: основной зачёт 94 = 38 + 30 + 26; весь реестр 104 = 40 первых + 32 вторых + 26 третьих места + 3 диплома III степени + 2 победы без места + 1 призёрство без места. Сводка всего реестра включает смежные результаты и не представляется медальным зачётом RoboKit.

Обе версии TDP обновлены 14 октября 2026 года: включены все победы из реестра, годовая статистика, фотография Roki-2 и ссылка на полный реестр. Сохранён объём по 3 страницы. Порядок проектов: Python Tutor, HSV online, StarKit, SimRoki, Emkod.


## Справочник соревнований

`data/competitions.json` содержит 27 событий по всем парам год/соревнование из реестра. На главной странице размещены описания и ссылки на организаторов отдельно от источников результатов. Подробный список: `docs/competitions.md`; ограничения проверки доступности: `docs/link-check-2026-10-14.md`.


Главная страница: `index.html` (RU) и `en.html` (EN), с переключателем языка. Дипломы сверены в `docs/personal-awards.html` и `docs/personal-awards-en.html`; повторные сканы не создают новые результаты. Сертификаты участия отражены только в справочнике событий.
