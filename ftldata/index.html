ПРЕДЛОЖЕНИЯ ДЛЯ ЦОД

От прототипов
к общей среде.

FTL DATA — тестовый сайт с конкретными предложениями для запуска в ЦОД лицея. Демонстрационные сервисы пока размещены вне ЦОД.

Предлагается использовать ресурсы ЦОД для курсов, проверки олимпиадных задач и Git-сервиса. Исследовательские направления — компьютерное зрение, нейросетевая ходьба, обучение роботов в симуляции и локальная языковая модель с базой знаний.

Общая инфраструктура нужна для длительных экспериментов, параллельной подготовки команд и хранения кода, датасетов и результатов. Ресурсы и порядок доступа согласуются с ИТ-подразделением.
