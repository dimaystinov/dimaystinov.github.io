# ЦОД ФТЛ / FTL DATA

Портал: https://dimaystinov.github.io/ftldata/
Основной сайт: https://ftldata.duckdns.org/

Все четыре видео сохранены в релизе ftldata-media-2026-10-30 этого репозитория. Плееры используют файлы GitHub Releases; обложки находятся в ftldata/media. SHA-256 всех загруженных файлов совпадает с локальными копиями.

Каталог, фильтры и стили работают на GitHub Pages. Помощник открывается на основном сайте, где работает его сервер.
